项目概览
  • 全称 液相旋光（蔗糖溶液）虚拟仿真实验平台
  • 定位 课程思政引领下的物理实验教学创新工具，面向高校大学物理实验课程
  • 架构 纯前端（HTML5 + Canvas 2D + Three.js + Chart.js），零后端依赖
  • 核心特色
    ✅ 三分视场实时仿真 ✅ 四步闭环状态机 ✅ 递进式教学设计 ✅ 双轨报告系统
  • 适用课程
    大学物理实验 光学实验 近代物理实验
⚙
技术栈
⚛ HTML5 ☴ CSS3 ⚙ JavaScript ES6+ ◇ Canvas 2D API ◆ Three.js WebGL 📈 Chart.js 𝔻 MathJax 3 🤖 智谱 GLM-4 AI
  • 前端框架：原生 HTML5/CSS3/JS，无重型框架依赖，确保轻量快速加载与跨平台兼容。
  • 图形渲染：Canvas 2D 用于二维光学仿真（旋光仪、马吕斯定律、三分视场）；Three.js 用于三维偏振态可视化展示。
  • 数据可视化：Chart.js 绘制散点拟合图、残差直方图、雷达评分图等多维度分析图表。
  • AI 集成：通过智谱 GLM-4 API 提供智能问答、实验指导、错误诊断等辅助教学功能。

核心特色亮点

四大维度构建沉浸式实验教学体验

📷
三分视场仿真

基于物理模型真实还原旋光仪三分视场观测效果，支持消光位置精确判定

📊
闭环状态机

四步流程（调零→测量→记录→计算）引导式操作，每步均有实时反馈与校验

📈
数据可视化

Chart.js 实时绘制散点拟合曲线、残差分布直方图、能力雷达图等

🤖
AI 智能助手

集成 GLM-4 大语言模型，提供智能答疑、实验指导、错误诊断等辅助功能
